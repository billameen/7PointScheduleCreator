# 7PointScheduleCreator

### Setup & Run Instructions

Follow these steps to get the project running on your machine:

1. **Install Python 3.13**
   Download and install Python 3.13 from the [official website](https://www.python.org/downloads/) if you don’t already have it installed.

2. **Get the Project Files**

   * Clone this repository using Git, or
   * Download it as a ZIP and extract it to a folder on your computer.

3. **Open a Terminal in the Project Folder**
   Navigate to the repository directory on your machine.

4. **Install Required Python Libraries**
   Run the following command to install all dependencies:

   ```
   pip install -r requirements.txt
   ```

5. **Set Up Environment Variables**

   * Find the file named `.env copy` in the project folder.
   * Rename it to `.env`.

6. **Add Your Credentials**
   Open the `.env` file and enter your 7PointOps username and password in the appropriate fields.

7. **Run the Program**
   Start the application by running:

   ```
   python main.py
   ```
